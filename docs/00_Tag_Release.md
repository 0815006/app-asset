# 发布说明 (Release Notes) - v1.0.0

本项目是一个全栈资产管理系统，包含基于 Spring Boot 的后端服务和基于 Vue 2 的前端界面。这是系统的第一个正式发布版本。

---

## 版本 1.0.0 - 2026-04-15

### 后端 (Java-Asset-Server)

#### 新功能
*   **核心系统初步开发**：实现了基于 Spring Boot、Maven 和 MyBatis Plus 的后端核心应用，提供稳定的后端服务。
*   **用户管理模块**：开发了用户注册、登录、认证（通过 Token 机制）和授权功能。
*   **安全加密升级**：全面启用 `BCryptPasswordEncoder` 对用户密码进行加密存储和校验，提升系统安全性。
*   **资产总数自动统计**：实现了产品资产总数（`asset_count`）的自动更新逻辑，涵盖上传、删除、恢复及同步等操作。
*   **资产文件管理**：引入了资产文件管理功能，包括上传、下载、收藏和状态跟踪。
*   **精选资产管理**：增加了精选内容的管理功能，用于组织和展示特定资产。
*   **产品管理**：实现了产品的增删改查操作，包括产品使用排名和用户收藏产品功能。
*   **搜索功能**：集成了基于 Solr 的搜索功能，并支持热门搜索追踪。
*   **编辑锁定机制**：实现了编辑锁定系统，以防止资产的并发修改。
*   **访问日志记录**：开发了记录资产访问日志的系统，用于审计和分析。

#### Bug 修复
*   **修复登录校验逻辑**：修正了登录时使用明文比对密码的问题，统一使用 `BCrypt` 校验。
*   **修复 Spring Security 认证冲突**：集成了 `JwtAuthenticationFilter`，解决了自定义 Token 拦截器与 Spring Security 之间的冲突。
*   **修复端口占用问题**：解决了由于 Java 进程未正常退出导致的启动异常。

#### 改进
*   **统一 API 响应**：实现了全局 `Result<T>` 类，确保所有控制器提供一致的 API 响应格式。
*   **全局异常处理**：建立了 `GlobalExceptionHandler`，用于集中和标准化错误处理。
*   **数据库 Schema**：提供了完整的数据库初始化脚本（`db_v2.sql` 和 `init_data.sql`）。
*   **MyBatis Plus 增强**：利用 `MyMetaObjectHandler` 自动填充创建/更新时间戳等公共字段。
*   **无状态认证优化**：配置 Spring Security 使用 `STATELESS` 会话管理，适配 JWT 认证模式。

### 前端 (Web-Asset-Vue)

#### 新功能
*   **前端框架初始化**：基于 Vue 2 和 Element UI 构建了前端项目，并使用 Vue CLI 进行开发。
*   **用户认证与页面路由**：实现了用户登录、全局路由管理和导航功能。
*   **修改密码功能**：新增了修改密码对话框，支持用户自主更新密码。
*   **强制重新登录机制**：在成功修改密码后，系统会自动清除本地会话并跳转至登录页。
*   **API 接口集成**：通过 Axios 封装了后端 API 请求，并实现了接口的集中管理。
*   **首页与多标签页**：设计了功能丰富的首页，包含业务概览、关系图谱、智能搜索和任务驱动等多个标签页。
*   **资产展示与管理**：开发了资产项、精选资产列表和文件更新对话框等核心组件。
*   **多媒体预览功能**：集成了超级预览组件，支持图片、Office 文档、PDF、文本和 XMind 文件等多种文件类型的在线预览。
*   **数据列表与排名**：提供了全局收藏榜、全局使用榜、最新更新列表、产品使用排名等多种数据展示维度。

#### Bug 修复
*   **修复 API 路径冗余**：解决了由于 `baseURL` 配置导致的重复 `/api/` 前缀请求问题。
*   **修复修改密码提示逻辑**：修正了对响应码的错误判断，确保成功提示能正常弹出。
*   **修复 Vue 警告**：解决了组件中属性重复定义的警告。

#### 改进
*   **规范化 API 调用**：统一了所有 API 服务文件的路径定义，增强了代码的可维护性。
*   **统一请求拦截**：配置了 Axios 请求和响应拦截器，统一处理错误提示和数据格式。
*   **全局状态管理**：引入 Vuex 进行应用级状态管理。
*   **组件化开发**：通过大量可复用组件的开发，提高了代码的模块化程度。
